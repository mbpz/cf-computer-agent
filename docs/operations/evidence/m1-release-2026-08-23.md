## Backup and migration

The native whole-database Wrangler export was attempted first and Cloudflare rejected it because the database contains FTS5 virtual tables (`cannot export databases with Virtual Tables (fts5)`). Migration was blocked until a successful logical backup was produced.

The approved fallback logical backup exported all 18 application tables, including `chunks` (the authoritative source for rebuilding FTS), while excluding only FTS5 virtual/internal tables. The backup remained outside the repository in a mode-700 temporary directory; each SQL file was mode 600. Total logical backup size: **9,822 bytes**. Only file sizes and SHA-256 values were recorded in the restricted operator shell; no row content was copied into this repository.
