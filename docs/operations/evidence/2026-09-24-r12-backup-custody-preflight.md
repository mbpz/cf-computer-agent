### 固定资源预算（工具限制，不是平台配额）

- 总逻辑行数（含迁移账本与独立 FTS corpus）最多 **10,000**。
- 逻辑归档 payload 最多 **16 MiB**；单行编码最多 **64 KiB**；schema 最多 **1 MiB**。
- schema object 最多 **1,000**；单表列最多 **128**。
- 分页 **20 行**；单 SQL 最多 **90,000 bytes**。
- 单 HTTP 响应最多 **2 MiB**，请求最多 **5,000**，单请求 **30 秒**，传输总计 **20 分钟**。
- 超限必须失败；CLI 不允许提高预算。20 分钟是工具传输上限，不是已批准停机时长，也不是完整备份/恢复耗时承诺。
