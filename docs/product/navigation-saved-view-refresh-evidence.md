# 已保存视图未知写入跨刷新保留（本地）

基线：`d50d731`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭该父项。

## 发现的问题

保存或删除已保存视图时，如果结果丢失，核对所需的名称、筛选和视图编号只留在当前挂载里。刷新后提示消失，再次保存可能创建另一份同名视图。创建接口本身不能安全重放。

## 实际变更

已登录成员发出前，先把创建（名称和筛选）或删除（视图编号）记在当前标签页。记不进去就不发送。刷新或重新挂载后仍显示未确认提示，离开被挡住，核对只读取服务端记录，不重发原写入。核对成功、明确拒绝后清掉记录；清不掉则继续锁住。记录损坏时不能再保存或删除，离开不被挡住，只能显式丢弃；丢弃不改变工作数据。没有成员身份时不记录。
