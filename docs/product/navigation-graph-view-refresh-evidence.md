# 工作图筛选跨刷新保留（本地）

基线：`3a6b20db`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

已登录成员在工作图里写了筛选词，或改了视角、时间和变更类型。这些选择只在当前挂载里。刷新或离开后再回来，筛选词清空，视角回到全部工作区，并按默认条件重新读取。未确认的图谱操作已经另有记录，这条缺口只针对当前看到的筛选。

## 实际变更

已登录成员的工作图筛选按成员记在当前标签页，和未确认操作分开。包含筛选词、视角、时间范围和变更类型。刷新或离开后再进入，恢复原来的筛选，并按恢复后的视角、时间和变更类型读取，不自动发起写入。筛选词只在当前页面过滤，不另外发请求。回到全部默认值后清除记录。记不进去时筛选仍留在当前页面，并提示刷新后不会保留。坏记录不套用，允许离开，只能显式丢弃；丢弃后才能再记下新筛选。这份记录不阻止离页。

## 验证

三条用例通过：改成筛选词 Launch、视角知识后可以离开，重建页面后两者仍在，并且读取使用知识视角；无法写入时筛选词留在页面并提示未能记录；坏记录可以离开且不套用，丢弃后才能记下新筛选词。图谱页面 19/19。前端类型、文案静态检查、操作清点（268 个文件、1149 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
