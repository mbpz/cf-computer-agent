# 通知未知更新跨刷新保留（本地）

基线：`fc6c6f7`，分支 `codex/functional-checklist-completion`。
归属：C05，不关闭该父项。

## 发现的问题

标记已读、批量已读和打开的结果如果丢失，锁只留在当前这次挂载里。刷新后锁和核对都消失，用户可以在还没读回列表时离开。

## 实际变更

已登录成员发出更新前，先把操作记在当前标签页的会话存储里。记不进去就不发送。刷新或重新挂载后，离开仍被挡住，直到列表和未读数重新读回并清掉这条记录。读回失败则继续锁定。401/403 清掉记录并解除锁定。记录损坏或属于别人时禁止继续更新，离开不被挡住，只能显式丢弃；丢弃不改变通知。没有成员身份时不记录，原有预览行为不变。

## 验证

三条路由用例先失败：刷新后存储是空的，记不进去仍会发送，坏记录也不拦更新。修复后同一组用例要求重挂载期间不重发、离开被挡住，列表读回后记录消失并允许离开；记不进去则不发送；坏记录禁用更新且可丢弃。通知路由与页面 38/38，壳层通知 13/13。前端类型、文案静态检查、操作清点（242 文件、1051 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 C05。没有数据库迁移。未执行远程迁移、部署或 push。
