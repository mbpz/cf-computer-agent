# 图谱动作进行中与未确认结果的离页保护（本地）

基线：`2e5448b`，分支 `codex/functional-checklist-completion`。
归属：A05 / R2-008、A02 图谱动作重放缺口、导航计划 Task 4 逐页所有者核对。

## 发现的问题

图谱检查器的“开始专注”“创建任务”“追加时间线”把请求状态挂在当前选中节点上。切换节点或改变视角时，状态和 clientKey 会被重置：

- 请求进行中可以直接离开，也可以切换节点后对另一个节点发起第二个动作。
- 响应丢失后只显示一个“可重试”按钮；选中别的节点再回来，原 clientKey 丢失，重试会生成新身份，可能产生重复任务或专注。
- 节点被筛选掉后，未确认的动作没有入口可以重试或核对。
- 400 这类明确拒绝与超时、5xx 显示同样的“未确认”，会诱导对已拒绝的请求反复重试。
- 401/403 只显示通用失败，旧图谱内容留在页面上。

## 实际变更

- 进行中或未确认的动作归页面所有，保存节点快照和 clientKey，不随选中节点或视角变化而重置。同一事件内的重复点击由同步 ref 去重。
- 进行中和未确认期间阻止普通离页和 `beforeunload`。守卫只在锁定期间注册，空闲图谱继续使用普通浏览器历史。
- 未确认时显示页面级提示 `data-graph-action-unconfirmed`，即使节点已被筛选掉，也能用同一节点和同一 clientKey 重试。服务端按 clientKey 幂等（任务 id=clientKey，专注和时间线按 clientKey 重放），所以重试不会重复创建。
- 明确 4xx 拒绝（408/429 除外）显示“操作被拒绝，没有保存”，丢弃 clientKey 并解锁；下一次点击使用新身份。
- 动作没有发出（deferred，例如目标不可在图谱内执行）时提示“操作没有发出”，不加锁。
- 401/403 进入 `forbidden` 状态，清空图谱并解锁。图谱读取本身遇到 401/403 时也进入同一状态，而不是显示可重试的通用错误。
- 卸载时解除守卫，迟到的回执不会再改写页面状态。
