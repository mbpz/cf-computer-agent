# 相关知识和反向链接读取失败不再消失（本地）

基线：`09291e4d`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

阅读页的相关知识和反向链接在读取失败后，整块面板消失。明确的空列表会说明没有相关知识或没有反向链接，失败却什么都不显示。

## 实际变更

读取失败时，对应面板说明读不到，并写明这不是空列表。服务器明确返回空列表时，仍显示暂无相关知识或暂时没有反向链接。

## 验证

一条用例先失败：相关知识和反向链接返回体无法读取时，页面上没有这两块面板。修复后两块都说明读不到，且不出现空列表文案。明确的空列表仍显示空结果。阅读链接、收藏、阅读数据和引用相关合计 24/24，笔记共享目录 2/2 仍通过。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
