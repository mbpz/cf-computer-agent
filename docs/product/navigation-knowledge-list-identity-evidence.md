# 知识列表缺少标题或发布时间不当成未命名（本地）

基线：`705ed2ac`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识列表里的条目没有标题时，卡片显示“Untitled knowledge”，发布时间仍在。没有发布时间时，卡片仍显示标题，日期被藏起来。

## 实际变更

标题或发布时间不是字符串时，知识页说明无法加载。标题和发布时间都是明确字符串时仍显示。明确的空标题仍显示未命名知识，并保留发布时间。

## 验证

缺少标题的用例先失败：页面显示“Untitled knowledge”和日期。缺少发布时间的用例先失败：页面显示标题，没有日期。修复后这两种都说明无法加载知识，原文不出现。明确的标题和日期仍显示。明确的空标题仍显示未命名知识，并显示日期。这条路径、知识数据、分页路由和成熟度路由相关合计 165/165。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
