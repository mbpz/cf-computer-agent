# 任务状态、进度、标签和关联进入活动记录（本地）

基线：`1007e4a`，分支 `codex/functional-checklist-completion`。
归属：R4-006，不关闭该原子或 C01。

## 发现的问题

任务的状态、进度、标签和知识关联已经写入审计，但成员活动流只返回投稿和知识事件。首页和知识页因此看不到这些操作。另一个成员的任务事件也不应出现。

## 实际变更

活动查询在原有可见规则之外，加入调用者自己的五类任务审计：`task.status_changed`、`task.progress_changed`、`task.tags_replaced`、`task.linked`、`task.unlinked`。字段修改和删除不进入这条流。他人的任务事件不返回。

首页和知识页能显示这五类文案。任务条目链到任务列表。知识页遇到不认识的活动类型仍会整段拒绝，所以客户端和文案与接口一起放行。

## 验证

活动用例先失败：插入这五类事件后，响应仍只有知识发布和投稿创建。修复后同一用例要求按时间倒序出现这五类，不出现 `task.updated`，也不出现另一个成员的任务。活动文件 4/4。类型检查、文案静态检查、操作清点（241 文件、1049 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

讨论回复和提及目前没有审计行，活动流仍不展示它们。不关闭 R4-006。没有数据库迁移。未执行远程迁移、部署或 push。
