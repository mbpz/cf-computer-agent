# 私人笔记列表缺少访问身份不当成自己的（本地）

基线：`9ed463dd`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

私人笔记列表里的笔记没有 `access` 时，知识页仍显示标题，并且不标“共享给你”。这条笔记被当成自己的。

## 实际变更

访问身份不是 owner 或 shared 时，私人笔记这一栏说明读不出来，不显示这条笔记。身份明确是 shared 时显示标题和“共享给你”；明确是 owner 时显示标题、不显示共享标记。明确的空列表仍隐藏这一栏，不当成读取失败。单行身份或标题不合法时仍丢弃这一行，不让整栏失败。

## 验证

缺少访问身份的用例先失败：笔记错误栏不出现，列表仍把这条笔记当成自己的。修复后这一栏说明无法读取，标题和“共享给你”都不出现。明确共享仍显示标题和“共享给你”。明确属于自己的笔记仍显示标题、没有共享标记。空列表仍隐藏笔记栏。笔记数据、分区读取和这条路径相关合计 12/12。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
