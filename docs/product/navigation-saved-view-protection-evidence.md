## 实现与契约修复

- 使用真实 SavedViewsService 的测试复现前端 POST/PATCH 错传 `filters.v` 导致 400：版本字段属于存储/读取格式，不属于写入输入。写入现在排除 v，成功回执仍严格要求 v=1 与完整数据。
- 搜索页保存视图名称接入共享草稿离页确认，提交读取同步最新字段；取消及最终导航被其他守卫拒绝均保留草稿，只在实际获准离页时丢弃。beforeunload 使用相同状态事实。
- 创建/删除以同步意图锁阻止重复提交和普通离页。创建要求 201、完整回执与名称/筛选匹配；更新要求 200、匹配 id；删除要求 204。200 HTML、部分成功体和错误身份回执不会当作已完成。
- 删除确认显示准确名称与影响，默认取消；每次确认使用独立决策对象，旧确认/取消不能作用于新弹窗，确认只能消费一次。
- member-keyed 路由隔离草稿和意图，卸载中止传输；旧成员响应及 apply/delete 回调无效。慢初始列表不会覆盖后续已确认创建。
- 保存和应用视图携带 q、spaceId、collectionId、tagIds、tagMode，不再仅保留搜索词。使用已提交 URL 的筛选快照；应用时清理旧页码。

## 未知结果的只读核对

后端创建使用随机 id，无幂等键，因此网络结果未知时不自动或手动重发 POST。仅提供显式只读核对：按不透明 cursor 逐页 GET，每页 50、最多 20 页，严格检查回执及游标循环。找到名称和完整规范化筛选一致的当前视图后收尾；不存在、不同、截断或读取失败都继续锁定。这证明目标当前状态存在，不证明原请求的因果归属。

删除核对仅接受 GET 指定 id 返回带 SAVED_VIEW_NOT_FOUND 的 404 为目标已不存在；普通 404、错误 id、无效回执和读取失败不解锁。没有新增跨刷新意图日志，不把 beforeunload 提醒宣称为持久恢复；初始可见列表仍为前 50 项，未冒充显示分页已经完成。
