# 已保存视图缺少列表不当成没有视图（本地）

基线：`2225c2d4`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

搜索页读取已保存视图时，返回体没有列表会被收成空数组。页面因此像是没有任何已保存视图，也不说明读取失败。

## 实际变更

返回体不是带列表的对象时，读取失败，页面说明无法更新已保存视图。服务器明确返回空列表时，不显示读取失败，也不列出视图。损坏的单行仍按原有约定略过。核对写入结果的分页读取本来就会拒绝缺少列表的返回体，这条没有放宽。

## 验证

一条用例先失败：已保存视图返回没有列表时，搜索页没有失败说明。修复后出现“Unable to update saved views. Please try again.”，且没有可应用的视图。明确的空列表不出现这句失败说明。已保存视图的数据、路由和搜索词用例仍通过，相关合计 46/46。前端类型、文案静态检查、操作清点（270 个文件、1163 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
