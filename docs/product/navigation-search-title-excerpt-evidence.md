# 搜索结果缺少标题或摘要不当成空白（本地）

基线：`ed8645f8`，分支 `codex/functional-checklist-completion`。
归属：B07、A02，不关闭这两个父项。

## 发现的问题

搜索结果没有标题时，页面显示“Untitled result”，摘要仍在。没有摘要时，页面显示“No excerpt available.”，标题仍在。缺字段被当成空白内容。

## 实际变更

标题或摘要不是字符串时，搜索说明暂不可用，不显示这条结果。标题和摘要都是明确字符串时仍显示原文。明确的空标题仍显示未命名结果，明确的空摘要仍显示暂无摘录。

## 验证

缺少标题的用例先失败：页面显示“Untitled result”和摘要。缺少摘要的用例先失败：页面显示标题和“No excerpt available.”。修复后这两种都说明搜索暂不可用，原文不出现。明确的标题和摘要仍显示。明确的空标题和空摘要仍显示未命名和暂无摘录。这条路径、搜索数据和成熟度路由相关合计 160/160。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
