# Memory Garden 2.0 Roadmap

日期：2026-09-08  
基线规格：[memory-garden-2.0-product-definition.md](./memory-garden-2.0-product-definition.md)

## 发布策略

```text
P0 产品内核冻结
  ↓
P1 工作台 Shell
  ↓
P2 收件箱与个人工作管理
  ↓
P3 知识与 AI Copilot
  ↓
P4 项目、日程、会议与协作
  ↓
P5 数据与治理
  ↓
P6 3D Landing Page
  ↓
P7 2.0 稳定发布
```

## P0：产品内核冻结

交付：产品定义、对象模型、状态机、权限矩阵、模块边界、Cloudflare 免费层约束和验收指标。

退出条件：所有一级模块有唯一职责；没有模块依赖付费能力才能运行；当前知识库、登录、权限、统计和任务能力都有保留映射。

## P1：工作台 Shell

交付：工作台首页壳、一级导航、全局搜索、命令面板、统一右侧上下文栏、主题、语言、用户菜单、通知入口和状态组件。

退出条件：用户可以从工作台进入任意已存在模块；管理员和普通成员菜单由服务端过滤；页面不显示内部 i18n key 或 `undefined`。

## P2：收件箱与个人工作管理

交付：Inbox、目标、项目、任务增强、子任务、依赖、个人日程、今日视图、专注模式和每周复盘。

退出条件：用户可以把一条输入转换为知识、任务、项目或日程；目标、项目、任务之间可追溯；任务完成和阻塞状态有统一状态机。

## P3：知识与 AI Copilot

交付：统一采集、知识详情、引用、版本、相似内容、AI 摘要、FAQ、时间线、研究报告、任务提取和 AI 工作台入口。

退出条件：AI 能力不再局限于聊天页；每种生成结果都能回到来源或明确报告缺口；Workers AI 不可用时有搜索/引用降级。

## P4：项目、日程、会议与协作

交付：项目主页、项目时间线、会议记录、行动项、评论、讨论、提及、通知、决策记录和团队活动。

退出条件：项目能够聚合目标、知识、任务、会议和成员；会议结果可以生成任务和知识；评论和审核行为有权限和审计。

## P5：数据与治理

交付：个人数据页、站点统计、内容质量、AI 使用量、成员活跃度、角色、菜单、空间、标签和审计增强。

退出条件：管理员统计专属；所有治理接口有服务端鉴权；统计数据不会泄露未授权内容；访问、登录和 AI 指标可以按时间范围查看。

## P6：3D Landing Page 产品演示

交付：公开匿名 Landing Page、等距微缩工作室、自动演示时间线、功能热点、登录 CTA、静态降级海报、暂停/跳过/重播、浅色/深色主题和减少动态效果模式。场景用 Inbox、Knowledge、AI、Tasks、Collaboration 和 Admin 等空间解释整个个人工作台 SaaS，而不是只展示知识库。

退出条件：Landing Page 不读取真实业务数据；自动演示可暂停、跳过和重播；所有 CTA 指向真实登录流程；WebGL 不可用时使用静态海报和 2D 说明；不新增运行时付费服务；登录后的核心工作仍完全在 2D 工作台完成。

## P7：2.0 稳定发布

交付：全量权限回归、OAuth 回归、i18n、无障碍、移动端、生产 smoke、成本证据、部署文档和回滚说明。

退出条件：当前功能无回归；新模块可独立关闭；Cloudflare 免费层约束有可观测证据；所有 2.0 核心验收项可复跑。

## 后续 2.1/3.0 预留

- Google/Outlook 日历连接器。
- GitHub Issues/Projects、Slack、Notion、飞书等导入或同步。
- 浏览器扩展、Webhook、API Token。
- 自动化规则和 Agent 工作流。
- 多工作空间和更高级的团队协作。
- 可选付费对象存储和大文件原件归档；不属于 2.0 免费层承诺。
