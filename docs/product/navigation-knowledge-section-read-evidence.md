# 知识页分区读取失败不当成空列表（本地）

基线：`73c52561`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识页的最近访问、待读、研究、私人笔记和活动在读取失败后被收成空数组，页面就像这些分区本来就是空的。收藏和研究、笔记在返回体缺少列表时也同样收成空。

## 实际变更

这些读取失败，或返回体没有列表时，对应分区说明读不到，并提供重试。重试只重新读取这些分区。服务器明确返回空列表时，分区仍不出现。损坏的单行仍按原有约定从收藏、研究和笔记里略过；最近访问本来就会整份拒绝。

## 验证

一条用例先失败：最近访问返回 500、收藏返回没有列表时，页面没有失败说明。修复后这两处都说明读不到，活动的空列表不报失败；重试后最近访问出现“Visited guide”，收藏仍说明读不到。收藏、最近访问和笔记的原有读取用例仍通过，相关合计 34/34。前端类型、文案静态检查、操作清点（270 个文件、1163 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

这只覆盖知识页上的这五个分区。不关闭 B07。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
