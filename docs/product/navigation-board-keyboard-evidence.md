# 看板方向键移动与窄屏横向到达（本地）

基线：`62781af`，分支 `codex/functional-checklist-completion`。
归属：R4-009，不关闭该原子或 C02。

## 发现的问题

看板改状态只能打开每张卡片上的下拉框。焦点在卡片上时，左右方向键不会移动任务。窄屏下列是纵向堆叠，要滚完上一整列才能看到下一列。

## 实际变更

卡片可聚焦。焦点在卡片上时，右方向键移到下一列、左方向键移到上一列，但只在该状态属于当前合法迁移时才发出和选择框相同的状态请求，并带上当前状态作为预期状态。完成列不能左移到阻塞，因为完成只允许回到待办。焦点在下拉框上时，方向键仍交给选择框，不移动卡片。移动锁定时卡片不可聚焦。四列放进横向滚动条，窄屏可以滑到下一列；宽屏仍排成四列。

## 验证

看板路由用例先失败：页面没有横向滚动容器。修复后同一用例要求容器可横向滚动、列不收缩换行，选择框上的右方向键不发请求，卡片上的右方向键把待办改成进行中并带上预期状态，完成卡片的左方向键不再发请求。看板页面与路由 54/54。前端类型、文案静态检查、操作清点（241 文件、1050 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
