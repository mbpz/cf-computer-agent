# 专注未开始草稿跨刷新保留（本地）

基线：`0bdb83d`，分支 `codex/functional-checklist-completion`。
归属：C04，不关闭这个父项。

## 发现的问题

已登录成员写了专注标题并选了任务，但还没开始。这些内容只在当前挂载里。刷新后标题和任务选择都消失。结果未知的开始已经另有记录，这条缺口只针对尚未开始的草稿。

## 实际变更

已登录成员的未开始草稿按成员记在当前标签页，包含标题和所选任务。刷新后恢复到开始表单，不自动开始。确认离开后清除记录。记不进去时标题仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新草稿。任务预检失败仍会清掉选择并保留标题。未知开始仍走原来的开始记录。

## 验证

三条用例先失败后通过：重建页面后标题和所选任务仍在且没有开始请求；无法写入时标题留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新标题。既有“确认放弃后选择不再出现”仍然通过。专注任务选择 72/72，与确认和页面合计 96/96。前端类型、文案静态检查、操作清点（257 个文件、1106 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 C04。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
