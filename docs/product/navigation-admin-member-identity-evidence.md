# 管理员成员缺少邮箱、角色或状态不当成可管理（本地）

基线：`7b5ba0b2`，分支 `codex/functional-checklist-completion`。
归属：D02，不关闭这个父项。

## 发现的问题

成员列表没有邮箱时，显示“Email unavailable”，角色和启用状态仍在，停用按钮仍可点。没有角色时，显示“Role unavailable”，邮箱仍在。没有状态或状态不是启用/停用时，显示“Status unavailable”，邮箱和角色仍在。陌生角色词会直接显示。

## 实际变更

邮箱不是非空字符串、角色不是 `admin` 或 `contributor`、状态不是 `active` 或 `disabled` 时，页面说明无法加载。三者都明确时仍显示邮箱、角色和状态。管理员仍显示，且没有贡献者的启用/停用按钮。

## 验证

缺少邮箱的用例先失败：页面显示“Email unavailable”和 contributor。缺少角色的用例先失败：页面显示邮箱和“Role unavailable”。缺少状态和状态为 banana 的用例先失败：页面显示邮箱和“Status unavailable”。陌生角色的用例先失败：页面显示邮箱和 owner。修复后这些都说明无法加载页面，原文不出现。明确的启用贡献者仍显示邮箱、contributor 和 Active。明确的停用贡献者仍显示 Disabled 和 Enable。这条路径与成员分页、刷新、确认、仪表盘和成熟度路由相关合计 238/238。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
