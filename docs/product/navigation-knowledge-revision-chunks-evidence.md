# 修订缺少分块列表不当成没有来源（本地）

基线：`2701a352`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识阅读页在修订返回体没有分块列表时，仍把条目打开，并显示“暂无来源位置”。

## 实际变更

分块不是列表时，整条修订读取失败，页面说明无法加载这条知识。服务器明确返回空分块列表时，仍显示暂无来源位置。损坏的单个分块仍按原有约定略过。

## 验证

一条用例先失败：修订没有分块列表时，页面显示暂无来源位置。修复后改为无法加载这条知识，且不再出现暂无来源位置。明确的空分块列表仍显示暂无来源位置。阅读数据、收藏、链接和引用相关合计 26/26，笔记草稿与共享 42/42 仍通过。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
