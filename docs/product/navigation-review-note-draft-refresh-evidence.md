# 审核备注草稿跨刷新保留（本地）

基线：`baac9b3`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

已登录成员在审核队列写下的驳回或退回备注，只存在当前挂载里。刷新或重建页面后备注消失，离开确认也会在下一次进入时无法恢复已经明确丢弃的内容。未知的审核决定本身已经另有记录，这条缺口只针对尚未提交的备注。

## 实际变更

已登录成员的未提交备注记在当前标签页，按成员保存。刷新后恢复到对应提交的驳回或退回表单，不自动提交。确认离开后清除记录。记不进去时备注仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新备注。未登录预览不写这条记录。

## 验证

三条用例先失败后通过：重建页面后备注仍在且不提交，确认离开后记录清除；无法写入时备注留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新备注。审核队列离开 29/29，与详情、评论、分页和相关审核页合计 229/229。前端类型、文案静态检查、操作清点（254 个文件、1096 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 A05。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
