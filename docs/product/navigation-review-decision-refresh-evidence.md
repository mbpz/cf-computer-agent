# 审核决定未知结果跨刷新保留（本地）

基线：`78eb204`，分支 `codex/functional-checklist-completion`。
归属：R6-003 与 A05，不关闭这两个父项。

## 发现的问题

发布、退回或拒绝如果结果丢失，原决定只留在当前挂载里。刷新后提示消失，可以再发一次不同的决定，也可能无法用原载荷取回已经生效的结果。

## 实际变更

已登录成员发出前，先把投稿、动作、路径和原载荷记在当前标签页。记不进去就不发送。刷新或重新挂载后仍显示结果未知，离开被挡住；重试发送同一载荷。读到终态、成功回执或首次明确拒绝后清掉记录；清不掉则继续锁住。记录损坏时不能再做决定，离开不被挡住，只能显式丢弃；丢弃不改变工作数据。没有成员身份时不记录。

## 验证

三条详情用例先失败：刷新后存储是空的，记不进去仍会发送，坏记录也不拦决定。修复后同一组用例要求重挂载不自动重发、离开被挡住，重试使用原载荷，成功后记录消失；记不进去则不发送；坏记录可丢弃后才允许提交。审核详情路由 45/45。前端类型、文案静态检查、操作清点（246 文件、1061 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
