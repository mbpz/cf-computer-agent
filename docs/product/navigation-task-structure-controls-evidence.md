# 任务编辑器的子任务与依赖（本地）

基线：`85c20af`，分支 `codex/functional-checklist-completion`。
归属：C01，不关闭这个父项。

## 发现的问题

子任务和依赖的版本条件写入已经在服务端成立，编辑器里没有对应控件。用户无法添加、改状态、移除，也无法在版本过期时看到冲突。

## 实际变更

编辑已有任务时可以添加子任务（固定编号、待办、当前位置）、把状态改为待办/进行中/完成/取消、完成或重新打开、按子任务自己的版本移除。也可以按父任务版本添加或移除依赖。这些写入走原有任务意图：发出前记在当前标签页，明确 4xx 清除并提示，409 重新读取并保留其余草稿，结果未知时不自动重发。刷新后子任务和依赖的未知结果留在列表上核对，不重开字段编辑器。

## 验证

三条用例通过：添加子任务带固定编号并按子任务版本移除；503 后刷新仍锁住离开，核对只读且不重发；子任务 409 提示已在别处更改，添加依赖带父任务版本。任务结构 3/3，与意图、编辑器路由、收件箱晋升和任务列表合计 155/155。前端类型、文案静态检查、操作清点（253 文件、1093 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
