# 问答回执缺少置信度不当成低置信度（本地）

基线：`fd56f8b0`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

成员提问后，回执带有答案但没有置信度数字时，页面仍显示这条答案，并标成低置信度。

## 实际变更

带幂等键的回执必须带回 0 到 1 之间的置信度，以及引用列表和来源列表。缺这些字段时，这一问保持未确认，可以按原问题重试，不显示答案，也不显示低置信度。回执明确给出 0.3 时，仍显示答案和低置信度。没有成员的预览请求仍按原有路径处理。

## 验证

一条用例先失败：没有置信度时页面显示“Low confidence”和答案正文。修复后显示未确认问题，答案和低置信度都不出现。置信度为 0.3 的回执仍显示答案和低置信度。问答数据、取消路由、成熟度路由和这条新用例合计 242/242。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

这只覆盖已登录成员的问答回执。不关闭 B07。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
