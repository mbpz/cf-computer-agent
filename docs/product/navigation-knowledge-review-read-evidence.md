# 知识回顾缺少列表不当成没有待办（本地）

基线：`a394f1da`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识回顾在返回体不是回顾结果、或没有条目列表时，被收成空清单。页面因此显示“此周期没有需要处理的知识”。

## 实际变更

返回体必须带上请求的周期、起止时间和条目列表，否则回顾读取失败，页面说明无法准备回顾清单。服务器明确返回空列表时，仍显示此周期没有需要处理的知识。损坏的单行仍按原有约定略过。周期与当前选项不一致时，仍然无法准备，不展示另一周期的条目。

## 验证

一条用例先失败：回顾返回没有列表时，页面显示此周期没有需要处理的知识。修复后改为无法准备，且不再出现那句空清单。明确的空列表仍显示空清单。回顾数据与周期用例仍通过，相关合计 10/10。使用这份接口的路由夹具改为真实空回顾，成熟度路由 158/158 仍通过。前端类型、文案静态检查、操作清点（270 个文件、1163 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
