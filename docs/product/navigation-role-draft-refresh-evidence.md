# 角色未提交草稿跨刷新保留（本地）

基线：`c6c7d8ef`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

已登录成员改了角色权限、待分配成员，或填写了新角色的键、名称和掩码，但还没提交。这些内容只在当前挂载里。刷新后都消失。结果未知的角色写入已经另有记录，这条缺口只针对尚未提交的草稿。

## 实际变更

已登录成员的未提交角色草稿按成员记在当前标签页，包含所选角色、权限掩码、待分配成员，以及新角色的键、名称和掩码。刷新后恢复到原角色的表单，不自动保存。确认离开后清除记录。角色写入一旦记入原来的写入记录，这份草稿就清掉。记不进去时改动仍留在当前页面，并提示刷新后不会保留。坏记录或无法对上的角色允许离开，只能显式丢弃；丢弃后才能再记下新草稿。

## 验证

四条用例通过：重建页面后权限、角色键、名称和待分配成员仍在且没有保存请求；无法写入时权限仍留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新的角色键；确认离开后记录清除，名称回到空白。角色页相关测试 73/73。前端类型、文案静态检查、操作清点（265 个文件、1138 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 A05。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
