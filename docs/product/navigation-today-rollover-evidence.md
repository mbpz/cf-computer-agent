# 今日页跨过 UTC 零点后重读（本地）

基线：`b8174435`，分支 `codex/functional-checklist-completion`。
归属：C04，不关闭这个父项。

## 发现的问题

今日页打开后一直显示当时读到的 UTC 日期。本地时钟跨过下一个 UTC 零点后，页面仍停在前一天，也不会再读 `/api/today`。

## 实际变更

今日页按本地 UTC 时钟安排下一次零点重读。到点后走原来的重试：先进入加载，再读当天快照，页面日期换成新的一天。若当时开着某条详情，这次重读会关掉它，避免前一天的条目留在新的一天上。离开页面会取消这次等待。手动重试也会按当时时钟重新安排下一次零点。
