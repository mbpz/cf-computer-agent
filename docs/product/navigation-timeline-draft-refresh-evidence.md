# 时间线未提交草稿跨刷新保留（本地）

基线：`91d0c59d`，分支 `codex/functional-checklist-completion`。
归属：C03，不关闭这个父项。

## 发现的问题

已登录成员在某个项目里写了时间线标题、详情、类型或时间，但还没添加。这些内容只在当前挂载里。刷新后都消失。结果未知的创建已经另有记录，这条缺口只针对尚未提交的草稿。

## 实际变更

已登录成员的未提交时间线按成员和项目记在当前标签页，包含标题、详情、类型、开始时间和截止时间。刷新后恢复到表单，不自动创建。确认离开后清除记录。创建请求一旦记入原来的创建记录，这份草稿就清掉。记不进去时标题仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新草稿。

## 验证

四条用例通过：重建页面后标题和详情仍在且没有创建请求；无法写入时标题留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新标题；确认离开后记录清除，回到同一项目时间线是空表单。项目时间线恢复 37/37。前端类型、文案静态检查、操作清点（263 个文件、1130 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 C03。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
