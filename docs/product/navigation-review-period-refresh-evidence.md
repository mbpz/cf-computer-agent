# 复盘周期与读取一致，并在刷新后保留（本地）

基线：`7ec3c9dc`，分支 `codex/functional-checklist-completion`。
归属：B07 与 C04，不关闭这两个父项。

## 发现的问题

已登录成员把知识回顾从本周改回今天后，页面显示今天，最后一次读取仍是本周。工作台复盘和知识回顾选过的本周，刷新后都回到今天，并按今天重新读取。

## 实际变更

知识回顾每次改周期都会按当前选项重新读取，包括从本周回到今天。已登录成员选中的本周按成员、并按知识回顾或工作台复盘分开记在当前标签页。刷新或离开后再进入，仍是本周，并按本周读取。回到今天后清除记录。记不进去时选项仍留在页面，并提示刷新后不会保留。坏记录不套用，允许离开，只能显式丢弃；丢弃后才能再记下本周。这份记录不阻止离页，也不发起写入。

## 验证

五条用例先失败后通过：知识回顾回到今天后最后一次读取是今天；重建页面后知识回顾仍是本周且读取本周，离页不被拦住；无法写入时选项留在页面并提示未能记录；坏记录可以离开且不套用，丢弃后才能记下本周；工作台复盘重建后仍是本周并读取本周。知识列表分页 8/8 仍通过。前端类型、文案静态检查、操作清点（269 个文件、1155 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
