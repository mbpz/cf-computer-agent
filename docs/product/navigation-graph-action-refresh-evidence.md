# 图谱未确认操作跨刷新保留（本地）

基线：`4f0292c`，分支 `codex/functional-checklist-completion`。
归属：A02，不关闭该父项。

## 发现的问题

图谱操作的结果如果丢失，客户端编号和离开锁只留在当前挂载里。刷新后提示消失，再次操作会换成新编号，可能重复创建。

## 实际变更

已登录成员发出前，先把节点和客户端编号记在当前标签页。记不进去就不发送。刷新或重新挂载后，仍显示未确认提示，离开被挡住，重试沿用同一个编号。成功、明确拒绝或撤权后清掉记录。记录损坏时不能发起新操作，离开不被挡住，只能显式丢弃；丢弃不改变工作数据。没有成员身份时不记录。

## 验证

三条页面用例先失败：刷新后存储是空的，记不进去仍会发送，坏记录也不拦操作。修复后同一组用例要求重挂载不自动重发、离开被挡住，重试使用原编号，成功后记录消失；记不进去则不发送；坏记录禁用按钮且可丢弃。图谱页面 16/16。前端类型、文案静态检查、操作清点（243 文件、1053 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
