# 笔记共享目录缺失不当成没人可共享（本地）

基线：`8f9dcc28`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

私人笔记的共享目录在 `/api/members/active` 返回体没有成员列表时被收成空数组。阅读页因此像是没有可共享的成员，并显示“暂未共享给其他成员”。

## 实际变更

返回体不是带列表的对象时，目录读取失败。共享区说明无法更新共享，并提供重试，不再显示“暂未共享给其他成员”。服务器明确返回空列表时，仍显示暂未共享，且没有重试。损坏的单行成员仍按原有约定略过。

## 验证

一条用例先失败：已保存的私人笔记收到没有列表的目录时，页面没有重试。修复后出现重试和“Unable to update note sharing.”，且不出现“Not shared with anyone.”。明确的空列表仍显示“Not shared with anyone.”，没有重试。笔记读取与共享决定的原有用例仍通过，相关合计 41/41。前端类型、文案静态检查、操作清点（270 个文件、1163 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

这只覆盖阅读页上私人笔记的成员目录。不关闭 B07。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
