# D01-B1 站点统计读取恢复：本地证据

日期：2026-09-15。分支：`codex/admin-audit-recovery`，基线：D01-A `72801b2`。范围仅限 B1 读取恢复；不表示合并、推送、部署或生产验收。

## 已实现

- 初始加载和同范围翻页失败可手动重试原 days/page/pageSize，不自动重试；同步 pending 锁拦截连续刷新/重试。
- 日期切换不展示上一范围汇总和访客；同范围翻页/刷新可保留旧结果，但明确标注尚未取得新查询数据。分页元数据始终跟随显示的结果，而非未成功的新页。
- 每代 effect 独立创建并释放请求 controller，AbortSignal 与完整查询校验阻止迟到结果覆盖；路由卸载取消，401/403 清除访客并显示权限状态，成员/权限投影改变使路由重新挂载。
- 日期沿用 1–31 个 UTC 自然日。7/14/30 为快捷选项，days=1 等合法 URL 不再显示成 7 天，重复 days 默认回退 7；日期或每页条数改变回第一页。中英文展示实际响应起止日期与旧结果提示。
- loader 严格验证非负安全整数、真实日历日期、区间跨度、响应 days/page/pageSize 与请求一致、daily 与 breakdown 结构；不再把畸形统计当作 0 或静默丢弃。保留数字分页严格规范化。
- 复用现有 shadcn Card/Button/PageState 和数字分页；没有新增 Cloudflare 服务、依赖、迁移、轮询或生产接口。
