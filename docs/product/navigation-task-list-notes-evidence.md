# 任务列表缺少备注不当成没有备注（本地）

基线：`39b1ac3c`，分支 `codex/functional-checklist-completion`。
归属：C01，不关闭这个父项。

## 发现的问题

任务列表没有备注时，页面仍显示任务标题，备注段落不出现，看起来像这条任务没有备注。

## 实际变更

备注不是字符串时，任务列表说明无法加载，标题不出现。明确的空备注仍显示任务，不显示备注正文。明确的备注仍显示标题和备注。
