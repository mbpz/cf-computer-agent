# 最近访问缺少次数不当成一次（本地）

基线：`305fc760`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

最近访问没有次数，或次数是 0 时，知识页把这一条显示成“Visits 1”，标题仍在。

## 实际变更

访问次数不是大于 0 的安全整数时，最近访问这一栏说明读不到，不会显示成空列表，也不会显示成一次访问。明确的次数仍显示标题和该次数。

## 验证

缺少次数和次数为 0 的用例先失败：错误栏不出现，页面把这一条当成可读。修复后这两种都说明这一栏读不到，标题和“Visits 1”不出现。明确的 4 次访问仍显示标题和“Visits 4”。这条路径与最近访问数据、知识分栏、首页、成熟度路由和工作台数据相关合计 183/183。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
