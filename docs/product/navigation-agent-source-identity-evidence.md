# 问答来源缺少标题或空间不当成未命名（本地）

基线：`d04af3b2`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

成员提问的回执里，来源没有标题时页面仍显示答案，并把来源写成“Untitled knowledge”。来源没有空间时，页面显示来源标题和“Context: Not provided”。

## 实际变更

带来源的回执缺少标题或空间时，问题保持未确认，不显示答案。标题和空间都明确时仍显示答案、标题和空间。明确的空标题仍显示未命名知识，并保留空间。

## 验证

缺少标题的用例先失败：页面显示答案和“Untitled knowledge”。缺少空间的用例先失败：页面显示标题和“Context: Not provided”。修复后这两种都保持未确认，答案和编造的来源不出现。明确的标题和空间仍显示答案、标题和空间。明确的空标题仍显示未命名知识并保留空间。这条路径与问答数据、回执读取和取消路由相关合计 95/95。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
