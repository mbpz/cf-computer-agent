# 知识修订缺少标题、发布时间或当前标记不当成未命名（本地）

基线：`3db86c99`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

修订没有标题时，阅读器显示“Untitled knowledge”，发布时间和正文仍在。没有发布时间时，标题和正文仍在，日期被藏起来。没有当前修订标记时，页面把这一条当成历史修订。

## 实际变更

标题不是字符串、发布时间不是非空字符串，或当前标记不是布尔值时，页面说明无法加载这条知识。三者都明确时仍显示标题、时间和正文。明确的当前修订不显示历史修订。明确为历史修订时仍显示历史修订。明确的空标题仍显示未命名知识，并保留时间。
