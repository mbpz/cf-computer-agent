# 审核队列未知决定跨刷新保留（本地）

基线：`712b82b`，分支 `codex/functional-checklist-completion`。
归属：R6-003 与 A05，不关闭这两个父项。

## 发现的问题

队列上的发布、退回或拒绝如果结果丢失，原决定只留在当前挂载里。刷新后提示消失，可以对同一条投稿再发一次不同的决定。详情页已经能保留决定，队列还不能。

## 实际变更

已登录成员发出前，先把投稿、动作和原载荷记在当前标签页，并记下当前成员正在核对的那一条。记不进去就不发送。刷新或重新挂载队列后仍显示结果未知，离开被挡住；重试发送同一载荷。读到终态、成功回执或首次明确拒绝后清掉记录；清不掉则继续锁住。记录损坏时不能再做决定，离开不被挡住，只能显式丢弃；丢弃不改变工作数据。没有成员身份时不记录。
