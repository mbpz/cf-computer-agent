# 讨论未提交草稿跨刷新保留（本地）

基线：`9429fcb`，分支 `codex/functional-checklist-completion`。
归属：C06，不关闭这个父项。

## 发现的问题

已登录成员在讨论里写下但还没发送的正文和回复对象，只存在当前挂载里。刷新或重建页面后草稿消失。结果未知的发送已经另有操作记录，这条缺口只针对尚未发送的草稿。

## 实际变更

已登录成员的未提交草稿按成员和讨论记在当前标签页，包含正文和回复对象。刷新后恢复到输入框，不自动发送。确认离开后清除记录。记不进去时正文仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新草稿。未知发送仍走原来的操作记录，不把草稿当成已发出的消息。

## 验证

四条用例先失败后通过：重建页面后正文和回复对象仍在且不发送；确认离开后记录清除，再次进入输入框为空；无法写入时正文留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新草稿。讨论路由与意图合计 74/74。前端类型、文案静态检查、操作清点（255 个文件、1099 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 C06。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
