# 空间未提交草稿跨刷新保留（本地）

基线：`8c6ff668`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

已登录成员打开新建空间并写了名称或标识，或者打开空间编辑改了名称，但还没提交。这些内容只在当前挂载里。刷新后回到空白或服务器上的原值。结果未知的空间写入已经另有记录，这条缺口只针对尚未提交的内容。

## 实际变更

已登录成员的未提交空间按成员记在当前标签页，和原来的写入记录分开。可以是新建的名称和标识，也可以是正在编辑的空间、新建集合或集合编辑。刷新后重新打开原来的表单并恢复字段，不自动提交。确认离开后清除记录。空间写入一旦记入原来的写入记录，这份草稿就清掉。记不进去时名称仍留在当前页面，并提示刷新后不会保留。坏记录或对不上的空间允许离开，只能显式丢弃；丢弃后才能再记下新草稿。

## 验证

五条用例通过：重建页面后新建名称和标识仍在，没有创建请求；无法写入时名称留在页面并提示未能记录；坏记录可以离开，丢弃后才能记下新名称；确认离开后记录清除，名称回到空白；重建页面后空间编辑名称仍在，没有保存请求。空间页相关测试 106/106。前端类型、文案静态检查、操作清点（267 个文件、1146 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
