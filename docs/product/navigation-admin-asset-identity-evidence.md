# 资产队列缺少名称或状态不当成未命名（本地）

基线：`21262e4c`，分支 `codex/functional-checklist-completion`。
归属：D02，不关闭这个父项。

## 发现的问题

资产没有名称时，显示“Unnamed asset”，解析状态和预览仍在。没有状态时，显示“Status unavailable”，名称和预览仍在。状态不是排队、处理中、成功、可重试失败或终态失败时，页面把这个陌生词当成状态，名称和预览仍在。

## 实际变更

名称不是非空字符串，或状态不在这五种之内时，页面说明无法加载。名称和状态都明确时仍显示。只有明确的可重试失败才显示重试。

## 验证

缺少名称的用例先失败：页面显示“Unnamed asset”和 succeeded。缺少状态的用例先失败：页面显示 launch.txt 和“Status unavailable”。陌生状态 banana 的用例先失败：页面显示 launch.txt 和 banana。修复后这三种都说明无法加载页面，原文不出现。明确的成功资产仍显示 launch.txt、succeeded 和 Preview。明确的可重试失败仍显示名称、failed_retryable 和 Retry。这条路径与资产分页、刷新、仪表盘和成熟度路由相关合计 232/232。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
