# 审核队列缺少标题、提交人或待审状态不当成可审（本地）

基线：`70e90b26`，分支 `codex/functional-checklist-completion`。
归属：B06，不关闭这个父项。

## 发现的问题

待审队列没有标题时，显示“Untitled submission”，提交人和待审状态仍在，发布、退回、拒绝仍可点。没有提交人时，显示“Submitter unavailable”，标题仍在。状态不是待审（例如 rejected）时，页面把这个词当成这一行的状态，标题和提交人仍在。

## 实际变更

标题不是字符串、提交人不是非空字符串，或状态不是 `review_pending` 时，页面说明无法加载。三者都明确时仍显示标题、提交人和 review_pending。明确的空标题仍显示未命名提交，并保留提交人和待审状态。

## 验证

缺少标题的用例先失败：页面显示“Untitled submission”和 member-a。缺少提交人的用例先失败：页面显示“Launch guide”和“Submitter unavailable”。状态为 rejected 的用例先失败：页面显示“Launch guide”和 rejected。修复后这三种都说明无法加载页面，原文不出现。缺少状态与 rejected 走同一校验，修复后也说明无法加载，不显示“Status unavailable”。明确的待审行仍显示标题、提交人和 review_pending。明确的空标题仍显示未命名提交。这条路径与审核数据、队列离开、审核分页、管理仪表盘和成熟度路由相关合计 261/261。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
