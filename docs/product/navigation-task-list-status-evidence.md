# 任务列表缺少状态不当成待办（本地）

基线：`b08732d9`，分支 `codex/functional-checklist-completion`。
归属：C01，不关闭这个父项。

## 发现的问题

任务列表里的任务没有状态时，卡片仍显示标题，状态标成待办。没有优先级时，优先级标成中。

## 实际变更

状态、优先级或进度读不出来时，任务列表说明无法加载页面，不显示这条任务。状态明确是待办、优先级明确是中时，仍显示这条任务和这两个标记。

## 验证

两条用例先失败：没有状态时页面显示“To do”和任务标题。修复后说明无法加载页面，标题和待办都不出现。没有优先级时同样无法加载，不显示“Medium”。明确的待办和中优先级仍显示。任务数据和任务路由相关合计 61/61。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
