# 收藏读取失败不当成未收藏（本地）

基线：`a20de720`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识阅读页读取收藏失败，或返回的不是布尔值时，按钮显示“加入收藏”，并标成未按下。这和服务器没有返回“未收藏”不是一回事。

## 实际变更

收藏读取只接受布尔值。失败或形状不对时，页面说明收藏状态读不到，不显示加入或取消按钮，也不发出收藏写入。服务器明确返回已收藏时，仍显示取消收藏。

## 验证

两条用例先失败：读取 500 和非布尔值都会出现“加入收藏”。修复后这两条通过，明确已收藏仍显示取消收藏。阅读页相关 58/58。前端类型、文案静态检查、操作清点（270 个文件、1156 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
