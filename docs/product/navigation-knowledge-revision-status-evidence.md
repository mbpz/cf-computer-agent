# 知识修订缺少来源身份不当成待索引（本地）

基线：`9ddad23e`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识修订没有索引状态时，阅读页仍打开，解析状态显示 pending。没有来源版本时，来源编号显示 unknown-source。

## 实际变更

来源版本不是非空字符串，或索引状态不是 pending、indexed、search_degraded、failed 之一时，阅读页说明无法加载这条知识。索引状态明确是 pending、并带有真实来源版本时，仍显示这条知识和 pending。

## 验证

两条用例先失败：缺少索引状态时页面显示 pending；缺少来源版本时显示 unknown-source。修复后这两种都说明无法加载，标题不再出现。明确的 pending 和来源编号 source-a 仍显示。阅读相关合计 103/103。前端类型、文案静态检查、操作清点（270 个文件、1165 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
