# 成员状态未知更新跨刷新保留（本地）

基线：`15db63f`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

启用或停用成员如果结果丢失，原变更只留在当前挂载里。刷新后锁消失，可以对同一成员再发一次状态变更。页面本来只在读到该行后才允许下一次变更，不会自动重发。

## 实际变更

已登录成员发出前，先把目标成员和目标状态记在当前标签页。记不进去就不发送。刷新后在只读列表读到该行之前仍挡住离开，并且不能再改这一行；读到该行后清掉记录，不重发写入。列表里没有这一行不能当成成功。清不掉则继续锁住。记录损坏时不能再改状态，离开不被挡住，只能显式丢弃；丢弃不改变工作数据。没有成员身份时不记录。

## 验证

三条用例先失败：刷新后存储是空的，记不进去仍会发送，坏记录也不拦变更。修复后同一组用例要求重挂载不自动重发、读取完成前离开被挡住，读到该行后记录消失；记不进去则不发送；坏记录可丢弃后才允许提交。成员刷新 3/3，与分页、确认合计 70/70。前端类型、文案静态检查、操作清点（249 文件、1072 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 A05。没有数据库迁移。未执行远程迁移、部署或 push。
