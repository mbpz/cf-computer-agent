# 自己发送的讨论消息进入活动记录（本地）

基线：`5cc659f`，分支 `codex/functional-checklist-completion`。
归属：R4-006，不关闭该原子或 C01。

## 发现的问题

发送讨论消息成功后没有审计行。活动流因此看不到讨论。回复和提及只进通知，不进活动。

## 实际变更

首次写入消息时记一条 `discussion.message_sent`。资源是讨论线程，元数据只有消息 ID，不含正文。同一客户端键的重放不再记第二条。活动流只把这条记录返回给发送者。首页和知识页显示“发送了讨论消息”，并链到该线程。他人的活动流不包含这条线程。

## 验证

讨论 HTTP 用例先失败：发送成功后审计查询为空。修复后同一用例要求恰好一条审计、重放仍为一条、发送者的活动流包含该线程、另一成员的活动流不包含。讨论与活动文件 16/16。类型检查、文案静态检查、操作清点（241 文件、1049 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

收件人仍只在通知里看到回复和提及，活动流不展示这些通知。不关闭 R4-006。没有数据库迁移。未执行远程迁移、部署或 push。
