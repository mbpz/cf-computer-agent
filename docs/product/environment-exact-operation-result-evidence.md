# 环境元数据：唯一操作编号、同编号安全重试、精确查询结果

基线 `0216778`；仅本地实现与验证。对象是环境创建、改名、删除，不是 VM 启动或 APK 安装验收。

## 已实现

- 每个新意图只生成一次 UUID，冻结目标、版本和完整请求体；页面显示编号。同编号重试复用原请求，不自动重发，不静默换版本。
- 新增 `GET /api/environments/operations/:operationId`：按当前会话 `member_id` 和编号读取不可变元数据回执，仍检查 `vm:use`；无写入、无分页依赖、无客户端成员覆盖、`Cache-Control: no-store`。未知或其他成员编号返回 404。
- 查询不依赖仍存活的环境行，因此删除后仍能查询创建、改名和删除各自的历史结果；生命周期报告不作为元数据结果返回。
- 查询和重试互斥。客户端核对编号、类型、目标、所属成员、预期字段及版本。404 不等于操作失败；未找到、网络错误或不匹配响应保留原意图。401/403、退出及切换账户清除私人数据，迟到结果不能恢复它。
- 成功后显示该操作的历史回执摘要（编号、类型、目标 ID、版本、名称或删除时间），明确不代表当前 VM 状态。后续列表读取失败不撤销已验证结果；新写入和账户关闭清除旧摘要。
