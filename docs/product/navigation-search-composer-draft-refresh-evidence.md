# 搜索未发送草稿跨刷新保留（本地）

基线：`d295c2a`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

已登录成员改了搜索词或填写了视图名称，但还没提交。这些内容只在当前挂载里。刷新后未提交的搜索词和名称都消失。结果未知的保存或删除已经另有记录，这条缺口只针对尚未提交的草稿。

## 实际变更

已登录成员的未提交搜索词和视图名称按成员记在当前标签页。刷新后恢复到表单，不自动搜索，也不自动创建视图。确认离开后清除记录。已经提交的搜索词不会再被当成未提交草稿。视图名称一旦进入保存记录，就不再留在这份草稿里。记不进去时搜索词仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新草稿。

## 验证

五条用例通过：重建页面后搜索词和名称仍在且没有创建请求；无法写入时搜索词留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新搜索词；确认离开后记录清除，回到原搜索页是地址栏里的搜索词和空名称；已提交的搜索词不会留成未提交草稿。搜索草稿 19/19，已保存视图路由 16/16。前端类型、文案静态检查、操作清点（259 个文件、1114 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
