# A05 知识阅读页笔记共享与撤销保护（本地）

日期：2026-10-02；基线 `800f139`；分支 `codex/functional-checklist-completion`。

## 本轮交付

- 新增共享生命周期 hook，绑定成员/知识项与已保存笔记。权限读取成功且存在 owner 笔记才加载目录和共享列表；首次保存成功后自动启用。排除本人；无效列表不得被当成空列表。
- 共享和撤销先显示精确笔记标题、目标成员 ID/邮箱与影响说明，默认取消。共享明确说明已保存笔记及未来更新可读，未保存草稿不共享；撤销不承诺收回已复制内容。取消零写入，过期确认/旧共享行回调不执行。
- 确认后同步持有一次性操作引用，重复点击仅一次 POST/DELETE；与笔记保存、草稿离页决策互斥，pending/unknown 阻止编辑、保存和离页。取消共享保留未保存草稿。
- POST 仅接受 HTTP 201 且笔记/接收人/未撤销状态匹配的回执；DELETE 仅接受 204。其他成功状态、损坏内容或网络异常保留未知结果锁。已核对的写前校验失败释放写意图，但需显式只读刷新后才能再次操作。
- 未知结果只能显式 GET 笔记权限及完整共享列表进行核对，不重发写入。共享要求目标成员当前有效；撤销要求完整有效列表中无该成员有效共享。缺失 envelope、坏行、重复接收人、错误笔记/成员、读取失败都不能证明成功。
- 成员/知识项卸载中止请求并使旧回调和迟到回执失效；没有把旧结果写入新成员界面。

## 仓库契约核对

`src/routes/library.ts` 定义 GET shares 200、POST 201、DELETE 204。`src/private-notes/service.ts` 在写入前拒绝非法或本人目标；`src/private-notes/repository.ts` 的列表先验证 owner，再返回该笔记全部共享（含撤销记录），当前无分页截断。故完整有效列表可证明目标的当前状态，**不证明原始请求的因果归属**。列表契约以后若分页，本核对必须同步调整。
