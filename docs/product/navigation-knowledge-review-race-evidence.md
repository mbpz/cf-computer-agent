# 知识回顾不采用过期周期的结果（本地）

基线：`6513e76a`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识回顾从今天改成本周后，页面可以先显示本周的条目。若打开页面时发出的今天请求更晚返回，本周选项仍选中，列表却被换成今天的条目。

## 实际变更

知识回顾按当前选项读取，并在选项变化时作废上一次读取。晚到的上一周期结果不再写入页面。返回体里的周期若与当前选项不一致，回顾区显示无法准备，不展示那份条目。

## 验证

晚到结果这条用例先失败：本周条目出现后，补上今天的响应，页面又变成今天的条目。修复后该用例通过，周期不一致的响应当成准备失败且不展示条目。原有复盘周期用例仍通过，合计 7/7。前端类型、文案静态检查、操作清点（270 个文件、1155 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
