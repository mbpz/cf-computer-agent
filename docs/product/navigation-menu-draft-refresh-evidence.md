# 菜单未提交草稿跨刷新保留（本地）

基线：`4c513be9`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

已登录成员打开菜单编辑并改了路径，但还没保存。这些内容只在当前挂载里。刷新后编辑框消失，路径回到原来的值。结果未知的菜单写入已经另有记录，这条缺口只针对尚未提交的编辑。

## 实际变更

已登录成员的未提交菜单编辑按成员记在当前标签页，包含新建或编辑、目标菜单，以及编辑框里的字段。刷新后重新打开原来的编辑框并恢复字段，不自动保存。确认离开后清除记录，字段回到该菜单已保存的值。菜单写入一旦记入原来的写入记录，这份草稿就清掉。记不进去时路径仍留在当前页面，并提示刷新后不会保留。坏记录或对不上的菜单允许离开，只能显式丢弃；丢弃后才能再记下新草稿。

## 验证

四条用例通过：重建页面后编辑框仍打开且路径仍在，没有保存请求；无法写入时路径留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新路径；确认离开后记录清除，路径回到已保存的值。菜单页相关测试 105/105。前端类型、文案静态检查、操作清点（266 个文件、1142 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。
