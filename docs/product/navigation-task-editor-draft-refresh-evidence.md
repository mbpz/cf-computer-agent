# 任务编辑草稿跨刷新保留（本地）

基线：`7cd82c6`，分支 `codex/functional-checklist-completion`。
归属：C01，不关闭这个父项。

## 发现的问题

已登录成员在任务编辑器里修改但还没保存的标题，只存在当前挂载里。刷新后编辑器关闭，再次打开时标题回到服务器上的原文。结果未知的保存已经另有任务意图，这条缺口只针对尚未发出的编辑。

## 实际变更

已登录成员的未保存编辑按成员和任务记在当前标签页，并带上当时的表单基线。重新打开后只保留相对基线改过的字段，不自动保存。确认放弃后清除记录。记不进去时标题仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新编辑。未知写入仍由任务意图恢复，不把草稿当成已经保存。

## 验证

四条用例先失败后通过：重建页面后重新打开仍是改过的标题且没有写入；确认放弃后记录清除，再次打开回到原标题；无法写入时标题留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新标题。任务编辑器路由 73/73，与任务列表、删除确认和收件箱晋升合计 157/157。前端类型、文案静态检查、操作清点（256 个文件、1102 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 C01。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。
