# 环境未提交草稿跨刷新保留（本地）

基线：`61d0e22d`，分支 `codex/functional-checklist-completion`。
归属：D04 / A05，不关闭这两个父项。

## 发现的问题

已登录成员写了环境名称、类型、任务编号，或在重命名框里改了名称，但还没提交。这些内容只在当前挂载里。刷新后都消失。结果未知的创建、重命名和删除已经另有操作记录，这条缺口只针对尚未提交的草稿。

## 实际变更

已登录成员的未提交环境按来源和成员记在当前标签页。创建草稿包含名称、类型和任务编号。重命名草稿包含目标环境和名称。刷新后恢复到表单或重命名框，不自动发送写入。确认离开后清除记录。创建或重命名一旦记入原来的操作记录，对应草稿就清掉；另一份还没提交的创建内容会留下。记不进去时名称仍留在当前页面，并提示刷新后不会保留。坏记录允许离开，只能显式丢弃；丢弃后才能再记下新草稿。

## 验证

五条用例通过：重建页面后名称、类型和任务编号仍在且没有创建请求；无法写入时名称留在页面并提示未能记录；坏记录可以离开，丢弃后才能保存新名称；确认离开后记录清除，回到环境页是空表单；重建页面后重命名框仍打开且没有修改请求。环境页 66/66。前端类型、文案静态检查、操作清点（264 个文件、1134 个候选，不是运行验收）和清单审计通过。清单仍是原 30、范围内 29、关闭 5、开放 24。

## 边界

记录不跨标签页，也不跨浏览器关闭。不关闭 D04 或 A05。没有数据库迁移。未执行远程迁移、部署或 push。没有在已登录浏览器里走通这条路径。这不是正式 VM 运行验收。
