# 研究计划缺少子问题不当成零进度（本地）

基线：`996efee7`，分支 `codex/functional-checklist-completion`。
归属：B07，不关闭这个父项。

## 发现的问题

知识页最近研究在计划没有子问题列表，或子问题一条都读不出来时，仍显示这条研究，进度是 0/0。

## 实际变更

这种计划使最近研究整栏读取失败，页面说明这一栏读不到，不会把它显示成空列表，也不显示 0/0。服务器明确返回空研究列表时，这一栏仍不出现。无法识别的其他坏行仍按原有约定略过。可读的子问题仍显示真实进度。
