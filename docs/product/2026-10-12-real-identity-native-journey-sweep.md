## C01 任务全旅程（任务创建/编辑/状态/截止/优先级 + 双标签）
| 步骤 | 实测 |
| --- | --- |
| 键盘打开 `新建任务` 弹层 | 弹层字段：`任务标题`/`任务备注`/`任务优先级(低中高)`/`任务截止时间(datetime-local)` |
| 创建（标题 + 备注 + 优先级=高 + 截止次日） | 行出现：`acct-task-… acct notes 编辑 待办 高 讨论 完成 删除`，`总计 1` |
| 编辑（`编辑:` 行操作 → 弹层改标题 → `保存任务`） | 行标题更新为 `…-edited`；弹层同时暴露 `任务状态`/`任务进度`/`任务标签`/`知识条目 ID`/`子任务标题`/`依赖的任务` |
| 状态（弹层内 `任务状态` 选 `已完成` → `保存状态`） | 行变为 `已完成 … 重新打开` |
| 真实双标签 | 第二个标签打开 `/tasks` 读到同一条（`总计 1`），删除后刷新为 `总计 0` |
| 删除（`删除:` 行操作 → 确认弹层） | 文案：`删除此任务？ <标题> (<id>) — 将永久删除此任务及其任务标签和关联。不会删除关联的知识内容。此操作无法撤销。`（`取消`/`永久删除`）→ 确认后 `总计 0` |

## C03 目标/项目归属、进度与计数对账
| 步骤 | 实测 |
| --- | --- |
| 创建目标 | 行：`acct-goal-… 进行中 进度 0% 管理关联任务 标记完成 归档`，`总计 1` |
| 创建项目 | 行：`acct-project-… 计划中 进度 0% 0 目标 0 任务 0/0 已完成 管理关联 时间线 标记完成 归档` |
| `管理关联` → 目标页签 → `关联: <目标>` | 确认弹层：`修改此项目关联？ <项目> · 目标: <目标> · 未关联 → 已关联. 仅添加此项目关联，不删除目标，也不修改其状态或进度。`（`取消`/`关联`）→ 目标行变为 `已关联 / 解除关联` |
| 切到 `任务` 页签 → `关联: <任务>` | 同一确认形态（`任务: <标题> · 未关联 → 已关联`）→ 项目行变为 `1 目标 1 任务 0/1 已完成` |
| 把该任务标记 `已完成` | 项目行同步为 **`1 目标 1 任务 1/1 已完成`**（`进度 0%` 为手工字段，不随任务完成率变化，符合既有说明） |
| `时间线` | 打开 `/projects/<id>/timeline`：含 `添加时间线事项`（类型：会议/决策/行动项/里程碑，开始/截止时间）与空态 `还没有时间线事项 总计 0` |
| 清理 | 任务 `删除` → `总计 0`；目标与项目经确认弹层 `归档` → `已归档`（二者无删除路径，故保留为已归档行；项目的任务链接随任务删除变为 `0 任务`，计数再次对账） |

## 观察（非缺陷）

## C04 收集箱/今日/日历/专注/复盘（写入旅程）
| 步骤 | 实测 |
| --- | --- |
| 收集箱创建（`内容` textarea + `加入收集箱`） | 行：`文本 待整理 acct-inbox-a-… 归档 转为任务`，`总计 2` |
| `归档` | 确认：`确认收集箱操作 <标题> (<id>). 待整理 → 已归档. 归档此项，不会删除内容，之后可恢复到收集箱。`（`取消`/`归档`）→ 行变 `已归档 … 恢复 转为任务` |

| `取消日程`（图标按钮 `aria-label="取消日程"`） | 确认：`要取消此日程吗？确认前请核对标题和时间。 <标题> (<id>). 2026年10月14日 09:00 – 2026年10月14日 10:00 (Asia/Shanghai). 仅将此日程标记为已取消，不会删除日程，也不会更改关联任务、项目…`（`保留日程`/`确认取消日程`） |

## C02 看板：移动、移动端与真实双身份隔离
| 步骤 | 实测 |
| --- | --- |
| 在 `/tasks` 建一张任务后打开 `/boards` | 四列 `待办/进行中/受阻/已完成`；卡片：`acct-board-… 中 移动到… 进行中 已完成 已取消` |

| 移动端（375 视口、触控仿真） | 看板正常渲染（卡片在 `进行中` 列），**横向溢出 0** |
| 真实双身份隔离 | contributor 看板：`进行中 1`（其任务）；**管理员真实会话**看板：四列全 `0` 且**不含**该任务 → 各自只看自己的看板 |
