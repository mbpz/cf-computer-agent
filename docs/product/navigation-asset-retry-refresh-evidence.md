# 资产重试未知结果跨刷新保留（本地）

基线：`5a600a7`，分支 `codex/functional-checklist-completion`。
归属：A05，不关闭这个父项。

## 发现的问题

解析失败后的重试如果回执丢失，锁只留在当前挂载里。刷新后可以在重新读取队列之前再提交一次。页面本来只允许重新读取来核对，不会自动重发。

## 实际变更

已登录成员发出前，先把资产编号记在当前标签页。记不进去就不发送。刷新后在队列读回该行之前仍挡住离开，并且不能再重试；读回后清掉记录，不重发 POST。清不掉则继续锁住。记录损坏时不能再重试，离开不被挡住，只能显式丢弃；丢弃不改变队列数据。没有成员身份时不记录，也不把普通后退改成异步离开闸门。
