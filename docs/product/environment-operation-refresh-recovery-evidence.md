# 环境元数据未决操作：同标签页刷新恢复

基线 `c4120d8`。只涉及环境创建、改名、删除；不是 VM 启动、联网或 APK 安装验收。仅本地实现、测试和提交。

## 行为

- 会话已验证的来源与成员组成 sessionStorage 键；保存唯一 UUID、类型、完整原始请求体、目标和预期版本。不开加密、不保存令牌、不创建备份任务。
- 发送前保存并回读校验。恢复结构、字段集合、范围、名称、目标、类型、请求和预期结果必须一致；损坏或越界记录拒绝，不静默删除。
- 刷新/重建账户所有者后恢复原意图。没有自动精确查询、自动写入或自动重试；页面仅正常加载成员列表。用户明确选择精确查询或同编号重试，后者保留逐字相同请求体。
- 成功回执经原意图校验后才清理日志。若清理失败，显示已验证历史摘要但保留原编号并阻止新写；可显式再次精确查询。明确服务器拒绝也必须确认本地日志已清理才能解锁。
- 配额、访问拒绝、静默丢写、不同意图冲突或清理失败不会发送新操作取代原编号。可明确“重新检查本地恢复存储”，该动作不发HTTP。不要人为删除未决记录绕过保护。
- 退出、撤权和旧所有者结束清空内存中的私人数据，但不删除未知结果记录；同一成员重新验证后可恢复。不同成员/来源不显示或重放它，旧账户迟到响应不能清理新所有者记录。
- 已保存的删除意图恢复时关闭对应环境网络；不会恢复网络或启动 VM。

## 不承诺及下一步

- sessionStorage是同标签页恢复，不是跨设备、关闭标签页/浏览器、清除存储或崩溃后的可靠持久队列。用户代理可能复制或恢复标签页存储，本实现不宣称全浏览器唯一实例；服务端仍按成员和原编号幂等。
- 自动化覆盖实际 React App 重挂载、控制器所有者重建及本地真实Worker/D1，不宣称原生浏览器硬刷新已人工验收。
- 无新增迁移、无读取/上传生产secret、无push/部署/远程写入；独立验收预览未更新。
- 仅完成D04元数据恢复子项；D04、G0、VM运行UI、离页边界及其他父项仍开放。下一允许继续本地离页边界与其他操作所有者对账，无新增本地外部阻塞；正式VM仍受G0限制。
