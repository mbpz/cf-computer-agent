## 统一完成标准

每个功能独立记录 implementation / verification / release / acceptance。只有“入口 → 输入校验 → 授权 API → 持久化 → 返回反馈 → 刷新回读”完整，才可称本地流程完成。

每项实施必须覆盖：服务端成员隔离、越权直达拒绝、适用列表分页、稳定幂等键、重复请求、并发冲突、取消/重试、空态/错误态、键盘与移动端，以及具体测试/浏览器证据。无后端能力的操作不得静默成功。部署与生产数据操作需另行授权。
