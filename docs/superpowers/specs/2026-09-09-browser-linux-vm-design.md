# 浏览器内 Linux 工作空间设计

日期：2026-09-09

状态：架构方向已获用户确认；本书面规格待审阅；尚未实现、部署或验收。

仓库基线：`main` / `128745a`。本文件不表示现有产品已具备 VM 功能。

## 1. 产品目标与范围

用户在自己的浏览器中打开工作台，创建、启动和维护一个运行于当前设备的独立 Linux 环境，在工作台内使用终端和文件管理。它服务于个人知识库相关的数据整理、脚本执行、资料下载和开发任务。

用户已确认的边界：

- VM 在访问工作台的浏览器内运行，不是在 Cloudflare 或其他云服务器上运行。
- 同时提供「个人环境」和「临时任务环境」，创建时由用户选择。
- 无图形桌面，提供终端、文件管理和环境管理。
- 需要联网，覆盖经过验证的软件仓库、HTTPS Git 和外部 API。
- 沿用工作台的用户隔离、分页、幂等和 shadcn 风格。

本规格新增的具体默认值属于此次书面审阅内容，不视为用户已逐项批准。网络中继的部署位置、维护主体和费用须另行授权；此次确认不授权购买资源、开放公共代理或部署生产服务。

首版不包含：控制宿主浏览器标签页或 Chrome 内部 VM、远程云 VM、图形桌面、后台永久运行、自动跨设备同步、Docker、通用 64 位软件兼容、SSH、入站服务、通用 UDP、AI 自动执行终端命令。

## 2. 架构选择及能力边界

采用 **v86 + 轻量 32 位 Linux 镜像 + 终端 UI + 受控 WISP 网络中继**。v86 为候选执行引擎，正式接入前必须完成原始文档复核和第 12 节的真实运行验证；本轮原始文档联网获取未成功，不能把候选技术能力当作已核实的当前兼容性。[S1][S2]

| 组成 | 负责 | 不负责 |
| --- | --- | --- |
| 浏览器 VM Runtime | 在当前设备执行 Linux、串口终端、磁盘与运行状态 | 云端计算、关闭浏览器后继续运行 |
| 浏览器本地存储 | 加密检查点、磁盘增量、恢复清单 | 自动云备份、无限容量、永久不被清理 |
| 工作台前端 | 环境列表、启动停止、文件操作、故障恢复、权限提示 | 伪造启动成功或模拟终端输出 |
| Cloudflare Worker + D1 | 鉴权、个人环境元数据、密钥授权、操作记录、网络授权 | 存储完整磁盘、执行 Linux、转发全部文件内容 |
| WISP 中继 | 为已授权环境转发受限出站 TCP | 托管 VM、提供公共代理或入站端口 |

替代方案的取舍：远程 Linux 容器不符合「当前浏览器内运行」；仅提供 JavaScript 开发运行时不等于独立 Linux 环境；其他浏览器 Linux 引擎需要额外核对其底层授权和兼容范围，本轮不同时引入第二套引擎。

技术约束：

1. 首版镜像选择仍有安全更新渠道的轻量 32 位发行版，必须实测可用的 shell、包管理器、HTTPS Git、curl 和证书库；不得仅凭发行版名称宣称支持。版本、架构、许可证、来源摘要和构建方法写入镜像清单，失败则停止后续接入，不静默替换为远程 VM。
2. v86 及其配套文件固定到具体版本/提交和摘要，不依赖生产环境的浮动 `latest`。只声明验证过的软件组合，不承诺所有 Linux 程序或性能等同本机虚拟机。[S1]
3. 本产品的 WISP 适配范围限定为出站 TCP，不承诺通用 UDP 和入站连接；网络 UI 必须体现这个边界。固定版本的实际支持范围须按网络文档及 G0 验证，不依赖未来扩展。[S2]
4. 运行时放入独立 Worker，主页面负责交互；实际串口、文件系统适配和 Worker 生命周期必须通过验证。Worker 不是抵御同源 XSS 的额外安全边界。
5. 首版承诺范围为通过实际验收的桌面 Chrome/Edge。其他浏览器根据能力检测提示试验性或不可用，不只依据浏览器名称放行；移动端可管理记录和查看说明，不承诺本地启动能力。

## 3. 两种环境与用户流程

| 行为 | 个人环境 | 临时任务环境 |
| --- | --- | --- |
| 创建 | 命名后持久保留管理记录 | 命名，可选关联自己的任务 |
| 运行 | 使用当前设备资源 | 使用当前设备资源 |
| 保存 | 主动保存；启用有界自动检查点 | 不自动持久化磁盘或运行快照 |
| 停止 | 默认保存成功后停止；失败时保留运行态供重试或导出 | 确认后释放运行态和临时文件，无法恢复 |
| 再次启动 | 当前设备上最近完整检查点；不存在时明确提示 | 从干净模板重新启动，不伪装为续接 |
| 手动导出 | 支持文件和加密环境备份 | 支持文件导出；首版不支持完整环境备份 |
| 删除 | 删除管理记录，并处理本机副本 | 删除管理记录及本机残留 |

创建类型不可原地切换，避免对持久性作出含糊承诺。需要保留临时结果时先导出文件，再导入新建的个人环境。

主流程：

1. 登录后从工作台「Linux 工作空间」进入列表，选择环境类型与名称。
2. 首次启动展示镜像下载大小、内存申请值、存储检测和联网状态；用户确认后加载。
3. Linux 就绪并输出可交互提示符后才显示「运行中」，下载完成不算启动完成。
4. 用户在终端执行操作，文件面板展示共享工作目录；可将选中文件明确导入知识库提交流程。
5. 离开详情页但仍在同一工作台 SPA 内时，运行时由工作台级控制器保留，顶部显示当前环境状态及返回入口。
6. 停止、退出登录、关闭标签页和删除分别处理，不使用同一个模糊的「关闭」动作。

第一版每个浏览器配置文件最多运行一个环境。启动第二个前须保存/停止当前环境；管理记录数量不等于同时运行数量。

## 4. 路由、权限与页面结构

新增路由：`/environments`（列表）、`/environments/:environmentId`（详情）。通过现有路由能力注册表、导航模块、页面解析和成熟度登记接入，不只增加菜单链接。

新增权限键 `workspace.vm`，在权限位图尾部追加，禁止复用已有或历史保留位。实施前重新核对最新位图与角色迁移；现有 `workspace.tasks` 不自动授予 VM 权限。联网仍需独立的管理员策略允许，不因页面可见而默认开放。

布局沿用 shadcn 的表格、按钮、Tabs、DropdownMenu、Dialog、AlertDialog、Tooltip 和反馈组件：

- 列表显示名称、类型、本机数据状态、最近活动、网络策略和操作菜单。
- 顶部紧凑工具栏显示运行状态、最近保存时间、启停、联网和更多操作。
- 详情以终端为主，文件区域可折叠；设置、操作历史置于标签页，不堆叠大型卡片。
- 左侧导航、文件列表、终端各自滚动，右侧内容不撑破现有工作台高度约束。
- 弹出层支持点击外部、Escape 和焦点恢复；停止临时环境、删除和覆盖恢复使用明确的确认对话框。
- 深浅主题、中英文、键盘导航、加载/空/错误/无权限状态同步验收。终端使用专业终端渲染器，不以普通文本框冒充终端。

环境列表和操作历史使用现有完整数字页码契约，默认 20 条，支持 20/50/100；筛选、排序变化重置页码，删除末页记录后校正页码。文件列表也提供数字分页，由文件适配器分页返回，不能一次向 UI 传入无限目录。终端为有上限的滚动缓冲区，不使用业务表格分页。

## 5. 生命周期、保存与故障恢复

生命周期明确区分：`stopped → loading → running → saving → stopped`；另有 `paused`、`restoring` 和 `error`。启动、保存、恢复由单个控制器串行化，以递增运行代次识别事件，旧运行的迟到事件不能改变当前环境状态。

- **暂停**：停止执行但保留内存，页面仍占用资源；不等于磁盘已保存或可以安全关闭页面。
- **保存**：短暂暂停，获取相互匹配的运行状态、磁盘增量和共享目录版本；写入新检查点、验证完整性后原子切换清单，最后恢复执行。任何一步失败保留上一完整检查点，不覆盖为半成品。[S3]
- **保存后停止**：保存成功才释放运行时；失败则允许重试、导出或明确选择放弃未保存变化。
- **强制停止**：二次确认，说明只保留之前完整检查点。临时环境说明全部未导出结果会丢失。
- **恢复**：先核对引擎、镜像、设备参数和文件版本兼容性；不兼容时禁止强行恢复，允许导出备份或使用对应旧版本恢复后迁移文件。
- **运行状态真实性**：D1 记录的是最后活动和操作事实，不把过期心跳显示为「当前仍在运行」。本机运行态以控制器为准，其他设备显示「本机未运行 / 其他设备状态未知」。

个人环境默认每 5 分钟尝试一次自动检查点，只在运行且上次保存已完成时执行。记录「上次成功保存」时间，不将保存请求时间当成成功；保留最近两个完整检查点，并在写入前预留额外空间。临时环境不启用此机制。

标签页关闭、页面崩溃、设备休眠和浏览器回收不能保证最后一次保存完成。正常退出提供保存提示；异常退出只保证能恢复此前已确认完整的检查点，不依赖 `beforeunload` 完成异步写盘。[S4]

多标签页以浏览器独占锁协调同一账户的运行时，写入检查点携带持有者与代次；不支持可靠锁的浏览器禁止启动，不能靠提示文案容许并发覆盖。不能因心跳超时直接夺取仍被持有的锁。跨设备个人环境副本彼此独立，没有云端自动合并。

恢复快照不恢复旧网络授权。所有中继连接重新鉴权，已有 TCP 会话按断开处理；失败的命令由用户检查结果，不自动重放 Git 推送、API 写入或包安装。

## 6. 本地数据、账户隔离与备份

所有私有 API 从认证主体取得 `member_id`；禁止采用请求体中的用户 ID 作为权限依据。列表、详情、任务关联、密钥授权、删除和网络票据均检查所属用户，跨用户访问返回一致的不可见结果。Cookie 认证的修改/授权接口沿用并验证现有同源及 CSRF 防护，不能只检查登录态；中继管理接口不向客体开放。

浏览器存储至少按部署来源、成员、环境、版本分区。只做路径前缀隔离不够：个人环境的检查点、磁盘增量和持久文件均加密存储，未登录或登录其他账户时不得解锁。

建议的密钥边界（须在实现安全评审中验证）：

- 每环境生成随机数据密钥，使用经过审查的 Web Crypto 封装进行认证加密，随机数不得复用；分块数据的附加认证信息包含成员、环境、检查点与块标识。
- 数据密钥由成员级密钥包裹；成员级密钥在 D1 仅保存密文，由独立 Worker secret 保护。授权接口只向当前有效成员释放其所需密钥，客户端仅在内存持有解密材料。
- 浏览器不持久化明文密钥、会话令牌或密码；日志不记录密钥、终端内容和文件正文。
- 这是防止账户混用和离线存储直接读取的措施，不宣称能抵御已控制设备、同源 XSS 或有密钥权限的服务管理员，也不宣称零知识加密。
- Worker secret 的备份、轮换和旧备份解密策略是发布前检查项；不读取或上传本地 `SECRETS_FILE` 来实现。

退出登录先拒绝新输入和新联网，暂停运行，尝试在仍可授权的退出流程中保存个人环境；明确完成或放弃后销毁运行时和内存密钥。会话突然失效时立即断网和暂停，不继续申请密钥；销毁前仅允许完成已持有密钥的本地检查点写入，写入超时则保留上一次成功版本。账户切换不得复用旧控制器、文件句柄或缓存。

环境备份是带有版本清单、摘要和加密数据的完整包，必须包含该检查点依赖的磁盘增量与文件，不能只导出内存状态。备份绑定原成员，仅允许该成员重新登录后在新环境中恢复；同账户可手动跨设备搬迁，但不提供自动同步。删除单个环境不销毁成员级解密密钥，因此此前导出的备份仍可恢复；永久删除账户并销毁成员密钥后，该账户的加密备份无法恢复。删除提示必须说明这个差别。

普通文件下载由用户显式触发，下载到系统目录的明文文件不受工作台账户退出保护，应在导出确认中提示。管理员停用账户会阻止后续授权，但不能远程擦除已导出的文件或已被用户复制的密钥。

设计不依赖浏览器批准持久化存储，也不假设固定的浏览器配额。[S4] 启动前检查存储能力与估算余量，空间不足时拒绝新检查点而不损坏旧版本。首版每个个人环境以 512 MiB 的单个完整检查点数据为产品上限，包含其内存状态、磁盘增量、共享文件和加密开销，不包含共享只读基础镜像；保存双版本及在途新版本所需空间另行检测，不能拿上限代替实际空间检测。256 MiB 客体内存为初始验证配置，网页实际内存占用会更高。

删除分为元数据删除与设备副本清理：当前设备立即清理可访问副本，其他离线设备无法保证立即擦除。环境删除记录在该账户存续期间保留最小墓碑信息，以便旧设备再次登录后清理；不能向用户声称「所有设备已删除」。

## 7. 文件与知识库衔接

首版文件面板管理挂载到客体的共享工作目录，不伪装成全 Linux 磁盘管理器。支持目录浏览、创建、重命名、删除、文本编辑、上传和下载；系统文件仍由终端操作。文件操作规范化路径、拒绝目录穿越，符号链接不能突破共享根目录。

文本编辑有大小上限和冲突检测：首版预览/编辑上限 1 MiB，保存携带读取时的文件版本；若终端已修改同一文件，则提示重载或另存，不静默覆盖。单次文件上传上限 20 MiB，检查剩余空间；大批量操作可取消，并逐项报告失败。

HTML、SVG、脚本等客体内容默认以纯文本预览，不在工作台源下执行。终端输出视为不可信数据，关闭任意自动剪贴板写入和自动链接打开；点击链接仅允许明确支持的协议，粘贴多行/控制字符命令前确认。[S7]

「导入知识库」是独立的用户确认动作：选择文件 → 检查类型/大小 → 确认空间和可见内容 → 使用现有 `/api/submissions` 提交流程 → 返回提交记录。不得直接创建已发布知识或绕过审核、资产开关及空间权限。重复提交沿用提交接口的幂等机制；不自动采集整个环境、不上传密钥和隐藏目录。

可选任务关联只允许用户自己的任务；任务删除不自动删除 VM，VM 停止也不自动完成任务。首版不让 AI 自动读取文件、获取网络票据或执行 shell，后续需要单独的授权设计。

## 8. 联网设计与中继安全

流量路径为：客体应用 → v86 虚拟网络 → 浏览器 WSS → 受控 WISP 中继 → 被允许的公网目标。HTTPS 由客体应用校验证书，中继不得注入工作台 Cookie、OAuth 令牌或替用户关闭证书检查。

网络默认关闭，首次联网需用户明确操作；未配置受控中继时显示「联网未配置」，不能自动连接公共演示中继。离线可用于开发阶段测试，但联网要求未验收时，整体功能不得标记完成。

授权协议：

1. 已登录用户为自己的环境发起网络授权请求，服务端检查成员状态、`workspace.vm`、网络策略、资源预算和环境代次。
2. 返回有效期 60 秒、一次性使用的票据，包含成员、环境、运行代次、策略版本与唯一标识；中继原子消费票据，重放不能建立第二条连接。
3. 浏览器连接固定 WSS 端点，在发送任何 WISP 数据前通过应用层首帧完成认证；令牌不得放入 URL 或持久日志。中继适配器与 v86 的这一握手兼容性必须实测，不假设原生 WISP 已提供工作台鉴权。
4. 已建立连接使用最多 60 秒的授权租期，浏览器按 30 秒间隔向工作台续租并交中继验证。续租绑定原成员、环境、代次和策略版本；到期或身份无效则中继主动断开，不因为 WebSocket 还活着就永久授权。
5. 正常退出立即关闭客户端连接；停用成员、撤销策略等服务端动作在最长一个租期内强制生效。缺少续租服务或超出免费预算时关闭网络，不绕过鉴权。

出站策略：[S6]

- 首版只允许管理员配置的目标域名集合和 80/443 端口，不提供用户随意选择中继地址的入口。API 域名、软件镜像、Git 重定向/CDN 的实际目标均需明确覆盖。
- 443 端口允许不等于进行了 HTTP 协议识别；安全边界是目标域名、最终 IP、端口、流量预算和身份，不虚称能识别所有隧道协议。
- 每次新连接解析并验证全部候选地址，拒绝本地、私网、保留、链路本地、组播、云元数据地址及对应 IPv6/映射形式。实际连接固定到已验证地址，不能校验后再次解析造成 DNS 重绑定漏洞。
- 不以字符串后缀匹配代替规范化域名比较，不接受任意 IP 字面量绕开允许域名规则。重定向后产生的新连接同样重新检查。
- VM 的 DNS 由经过验证的中继适配路径处理，不开放任意 UDP。HTTPS Git 和包管理在此约束下逐项验证；Git LFS、子模块、镜像跳转未测试时不列入承诺范围。
- 默认限制为每成员 1 个联网环境、每环境 8 条出站 TCP 流、每自然 UTC 日 300 MiB 双向有效载荷。它们是首版产品预算，不是 Cloudflare 官方额度；中继按实际字节统计并跨连接/重连累计，不能由客户端上报或重新登录重置。
- 网络操作日志只记录环境、目标域名、结果、流量计数和时间，不记录请求正文、令牌、终端输出或文件内容。

中继部署必须单独确认：运行平台、TLS 域名、维护责任、策略配置和支出上限。当前不承诺标准 WISP 服务可直接部署到 Cloudflare Workers，也不把其他 Cloudflare 产品的免费额度视为已获授权的预算。若找不到经验证且获授权的部署方式，应报告联网阻塞，不把架构改为远程 VM。

## 9. 服务端契约与幂等

新增独立的环境服务边界，不把运行控制塞入通用任务服务。概念实体包括：成员所属环境、个人密钥封装、操作幂等记录、网络策略/授权记录和删除墓碑。D1 不存储 VM 内存镜像、终端全文、完整磁盘或私有文件内容。

拟定 API 契约（实施计划细化类型、错误码与迁移）：

| 接口 | 职责 | 关键约束 |
| --- | --- | --- |
| `GET /api/environments` | 列表与筛选 | 当前成员；数字分页；稳定排序 |
| `POST /api/environments` | 创建管理记录 | 类型、名称校验；创建操作幂等 |
| `GET/PATCH /api/environments/:id` | 详情、名称/任务关联 | 所有者检查；版本冲突检测 |
| `DELETE /api/environments/:id` | 删除记录并生成清理墓碑 | 重复删除安全；运行中需先停止 |
| `GET /api/environments/:id/operations` | 操作历史 | 当前成员；数字分页；不含敏感正文 |
| `POST /api/environments/:id/operations` | 上报本地生命周期事实 | 代次、事件 ID；不是远程启动 API |
| `POST /api/environments/:id/network-tickets` | 初次联网授权 | 所有者、策略、一次性票据 |
| `POST /api/environments/:id/network-renewals` | 续租 | 原授权、代次与当前策略仍有效 |
| `POST /api/environments/:id/key-access` | 授权解锁本机数据 | 有效成员、所有者；响应禁止缓存 |

恢复备份时另设成员级恢复授权契约：只解锁归属于当前成员且通过完整性校验的备份密钥封装，不依赖原环境记录仍存在；先创建新的个人环境，再写入本地数据并报告结果。不得把已删除环境的详情接口重新开放作为恢复捷径。

幂等规则：

- 修改请求使用客户端稳定操作 ID；服务端将成员、操作种类、目标和请求摘要共同绑定。相同操作 ID、相同内容返回原结果；同 ID 不同内容返回冲突，不能执行第二次。
- 创建环境和其幂等记录原子提交；名称更新等修改使用版本前置条件，不因客户端重试丢失其他标签页的更新。
- 分页沿用 `src/pagination.ts` 的严格参数检查与 20/50/100 页大小，环境默认按不可变创建时间及 ID 排序；历史按事件序号排序。
- 本地启动/保存/停止控制器同样以操作 ID 和代次去重，重复点击不会创建两个 VM、两个保存流或两次破坏性删除。
- 发放票据的幂等返回不代表票据能重复消费；原票据已消费或过期时，显式新建授权操作，不通过自动 HTTP 重试增加连接。
- Linux 内部命令及外部 API 的副作用不由上述幂等保护。网络中断导致结果未知时显示「请检查实际结果」，禁止自动执行第二遍。
- API 错误沿用现有结构，包含明确的 `retryable` 布尔值；只有确实安全的操作才展示重试。

元数据与本机快照不做虚假的跨端事务：UI 分别显示「本机保存成功」与「管理记录同步失败」。管理记录上报失败不得回滚已完整保存的数据；重试上报不能再次执行客体命令。

## 10. 镜像分发、Cloudflare 与运行预算

公共基础镜像不包含用户数据、密钥或私人仓库。采用可重复构建、明确许可证和完整性摘要的版本清单，镜像被篡改或摘要不符时拒绝启动。

Cloudflare Workers 静态资源的单文件、文件数量和账户限制须按实施时官方文档复核，本轮不将任何额度数字标记为已在线确认。[S5] 设计暂以每个分块不超过 16 MiB 作为产品目标，若超过部署时的平台限制则进一步降低，并提供明确的分块读取适配；不能把一个超限磁盘文件直接上传后期待平台自动支持。范围读取、断点恢复、缓存版本切换和失败重试均需真实验证。

引擎、WASM、镜像和终端依赖只在进入环境功能并按需启动时加载，不进入匿名首页或普通知识库页面的首屏包。公有只读镜像可共用缓存，私有数据和授权接口不得进入公共缓存或 Service Worker 通用缓存。

当前 CSP 以同源脚本和连接为主；接入只能添加经过验证的最小 WASM、Worker 与固定 WSS 许可，不全站添加 `unsafe-eval`、任意连接源或关闭 CSP。若依赖跨源隔离，先验证 GitHub OAuth、弹窗和现有资源兼容性，不全站盲目启用 COOP/COEP。

后台仅继续使用经验证符合本项目免费约束的管理资源。上线前估算成员数、环境数、授权续租请求、D1 读写/存储、镜像资源和中继流量；达到预算关闭新联网授权或降级为明确的离线状态，不自动升级付费服务。预算限制必须在服务器/中继执行，前端文案不能充当配额控制。

## 11. 实现边界与现有产品衔接
