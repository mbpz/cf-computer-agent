## 步骤 2：失败测试 → 最小回环服务

文件：`tools/browser-vm/connector-probe/server.mjs`、`scripts/browser-vm-connector-probe.test.mjs`。

- [x] 先运行失败测试，确认目标模块尚不存在。
- [x] 只绑定 127.0.0.1，明确配置唯一 HTTPS 页面来源；不允许通配、路径、空来源或公网绑定。
- [x] 固定 `/probe` WebSocket 路径，无查询参数；校验 Host 与精确 Origin。
- [x] 本机控制页的同源 POST 才能生成 30 秒一次性随机凭据；只保留摘要，最多一个待用凭据，新码使旧码失效。
- [x] 首帧鉴权期限、帧大小、尝试/连接数量、会话期限均有界；错误/过期/重放不建立握手；退出清理资源。
- [x] 握手只返回 probe-ready；拒绝后续消息。不导入 TCP 转发器，不创建目的地址连接。这不是正式成员鉴权。
- [x] 测试覆盖真实 HTTP/WebSocket 的来源隔离、凭据消费、错误协议、容量、超时、退出和端口冲突。
