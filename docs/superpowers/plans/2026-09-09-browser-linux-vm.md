# 浏览器内 Linux 工作空间 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 本任务按用户要求在当前分支顺序执行，不自行创建其他任务或调用子代理。

**Goal:** 完成工作台内真实的浏览器 Linux：个人/临时环境、受控联网、终端与文件、保存恢复、用户隔离、知识库提交和完整验收。

**Architecture:** Linux 在访问者的浏览器执行，Cloudflare 管理成员所属的元数据与授权，不运行 Linux。独立 Runtime、加密本地存储、文件桥接通过类型契约连接。2026-09-10 用户进一步要求下载使用浏览器所在电脑的网络；既有 WISP 仅保留为本地验证背景，不能默认以远程出网满足该要求。先核实浏览器直接读取及客体接入边界，再接入正式页面。

**Tech Stack:** TypeScript、React/shadcn、v86（候选固定版 0.5.458，实施前核对包内容）、Web Worker、IndexedDB/Web Crypto、Cloudflare Worker/D1、受控 WISP。

**Spec:** `docs/superpowers/specs/2026-09-09-browser-linux-vm-design.md`

## Global Constraints

- 两种类型都必须完成；不以仅离线、模拟 shell、JavaScript 沙箱或远程云 VM 替代目标。
- 每个私有查询/修改由认证主体派生 `member_id`，跨用户资源不可见；列表采用 20/50/100 完整数字页码。
- 同操作 ID、相同请求返回原结果；同 ID、不同请求冲突；客体命令不自动重放。
- 当前浏览器配置文件最多一个运行实例；个人环境有界检查点，临时环境不保存完整快照。
- UI 沿用 shadcn、中英文、深浅主题、焦点/弹出层和独立滚动。
- VM 不进入匿名首页首屏依赖；私有文件不进入公共缓存、D1 或日志。
- 不读取/上传 `SECRETS_FILE`，不推送、部署、开通公共代理或购买资源。
- 下载使用访问者浏览器所在电脑的网络；不隐式切换远程中继，不默认安装本地辅助服务。浏览器读到响应不等于客体 `apk`/`git` 已联网。
- G0 未通过，不开始后续正式页面接入；中继资源授权缺失不得改报整体完成。
- 每一任务按失败测试 → 最小实现 → 正向/反向测试 → 记录证据推进；最终所有 VM-001～038 逐项验收。

## G0 接口与文件责任

`scripts/browser-vm-artifacts.mjs` 只负责验证输入的版本化引擎/镜像清单和本地文件摘要；不下载、不启动、不执行脚本、不修改业务文件。`scripts/browser-vm-artifacts.test.mjs` 使用临时目录和真实字节验证它，所有临时数据由测试自行清理。

```ts
type Artifact = {
  role: 'engine' | 'wasm' | 'bios' | 'vga-bios' | 'kernel' | 'rootfs';
  path: string; // 相对于明确提供的资源根，禁止绝对路径、目录穿越及越界符号链接
  bytes: number;
  sha256: string; // 64 位小写十六进制
  source: string; // https 来源，不包含认证信息
  license: string; // 明确声明，不能是空白
};
type Manifest = {
  schemaVersion: 1; engineVersion: string; imageVersion: string;
  rootfsMode: 'embedded' | 'external'; artifacts: Artifact[];
};
// embedded 不接受单独 rootfs 角色；external 必须包含 rootfs，不能漏报磁盘。
// 验证失败抛出可定位到具体资源的错误，任何必需角色缺失都不成功。
verifyArtifacts(manifest: unknown, root: string): Promise<{ artifacts: number; bytes: number }>;
```

引擎/API 获取后才确定 `tools/browser-vm/probe.mjs` 的真实构造参数。探针必须调用真实 v86，对 Linux 串口执行固定、不涉及用户文件的测试命令；不做 echo 成功标志替代内核启动。真实镜像和二进制放在明确的开发资源目录，文件摘要写入清单，许可证同时归档；不得未经审核提交大型二进制。
